# Колесо для двоих (демо)

Статичное демо-приложение для Telegram Mini App: колесо на 8 секторов, в каждом подсказки и игры для двоих.
Без сервера, данные не собираются. Тексты, сектора, цвета и ссылки в `config.json` (копия для открытия файла напрямую: `config.js`).

Шрифт Golos Text под лицензией SIL OFL 1.1 (текст лицензии в `fonts/`).
