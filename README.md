# Колесо возможностей (демо)

Статичное демо-приложение для Telegram Mini App: колесо на 8 секторов, карточка результата, анимации.
Без сервера. Тексты, названия секторов, цвета и ссылки лежат в `config.json` (копия для открытия файла напрямую: `config.js`).

Шрифты Unbounded и Manrope под лицензией SIL OFL 1.1 (тексты лицензий в `fonts/`).
Ссылка "Написать" в `config.json` пока заглушка.
